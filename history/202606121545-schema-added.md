# 修改记录: respo/alerts 强类型标注覆盖与编译校验 (2026-06-12)

## 知识点与变动树

1. **alerts 插件项目类型标注引入**:
   - `respo/alerts` 是一个常用的对话框、弹窗和抽屉等交互组件的钩子基础库。原先其中的大多数全局定义与常量（如 `dev?`, `site`, `store`, `backdrop`, `button`, `card` 等）均被标注为宽松的 `:schema :dynamic`。
   - 现为其补充了精准且经编译器验证的高覆盖率强类型 schema 标注。

2. **核心 Schema 控制更新 (在 `respo/alerts/calcit.cirru` 中)**:
   - `respo-alerts.config/dev?` => `:schema :bool`
   - `respo-alerts.config/site` => `:schema :map`
   - `respo-alerts.schema/confirm-button-name` => `:schema :string`
   - `respo-alerts.schema/input-box-name` => `:schema :string`
   - `respo-alerts.schema/store` => `:schema :map`
   - `respo-alerts.style/backdrop` => `:schema :map`
   - `respo-alerts.style/button` => `:schema :map`
   - `respo-alerts.style/card` => `:schema :map`
   - `respo-alerts.main/*reel` => `:schema :ref`
   - `respo-alerts.main/dispatch!` => `:schema $ :: :fn $ {} (:return :none) (:args $ [] :list)`
   - `respo-alerts.updater/updater` => `:schema $ :: :fn $ {} (:return :map) (:args $ [] :map :list :string :number)`
   - `respo-alerts.util/focus-element!` => `:schema $ :: :fn $ {} (:return :none) (:args $ [] :string)`
   - `respo-alerts.util/select-element!` => `:schema $ :: :fn $ {} (:return :none) (:args $ [] :string)`

3. **编译与质量保障**:
   - 切换工作区至 `respo/alerts`，通过新版 `cr --check-only` 语法及类型预处理器验证全量通过 🟢。
   - 通过新版 `cr js` 成功生成和合并 JavaScript 静态脚本。
