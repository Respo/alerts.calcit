# Respo dependency alignment / 对齐 Respo 依赖链

## 中文

- 将 Reel 升级到 0.6.10、respo-markdown 升级到 0.4.28、Respo UI 升级到 0.7.13。
- 中间模块已经完成 Calcit 0.13.64 回归并发布，Alerts 现在可以使用一致的 Respo UI 版本链。
- 通过 strict Caps 与现有 quality baseline 守门，要求无版本选择 warning，且不改变 Alerts UI/API。

## English

- Upgrade Reel to 0.6.10, respo-markdown to 0.4.28, and Respo UI to 0.7.13.
- The intermediate modules have completed Calcit 0.13.64 regression coverage and have been released, allowing Alerts to use one consistent Respo UI dependency chain.
- Enforce strict Caps and the existing quality baseline with no version-selection warning and no Alerts UI/API changes.
