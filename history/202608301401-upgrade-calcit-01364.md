# Calcit 0.13.64 upgrade / 升级 Calcit 0.13.64

## 中文

- 将 Alerts 的 Calcit CLI 与 `@calcit/procs` 从 0.13.63 同步升级到 0.13.64。
- 保持 Respo UI 0.7.12 及现有 strict dependency chain 不变，避免中间模块尚未发布时产生版本选择 warning。
- 保持 Alerts UI/API 与升级 baseline 不变，并通过 strict Caps、静态分析、JS codegen 与 Node 24 Vite build 验证。

## English

- Upgrade the Alerts Calcit CLI and `@calcit/procs` together from 0.13.63 to 0.13.64.
- Keep Respo UI at 0.7.12 and preserve the existing strict dependency chain, avoiding version-selection warnings before intermediate modules are released.
- Keep the Alerts UI/API and upgrade baseline unchanged, with strict Caps, static analysis, JS codegen, and Node 24 Vite build coverage.
